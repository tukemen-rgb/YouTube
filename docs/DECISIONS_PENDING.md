### D1 への追加材料(2026-09-03、サイクル 21 市場調査より)

日本語圏の競合(Vrew・KIRARI・OpusClip)は音声認識ベースの字幕が標準装備。
字幕が無いと「編集した感」で見劣りする、が調査の結論。Whisper 採用判断の
材料として docs/MARKET_RESEARCH.md を参照。

### D1 への追加材料(2026-09-09、サイクル 39 実測より)

音声認識を使わずにどこまで行けるかを試した(発話らしさ = 音量が人の音節
の速さで上下しているかを測る近似、v0.22)。**行ける範囲と行けない範囲が
数字で出た**ので、判断材料として置いておく。

行けたこと:

- 話し声・持続音・ノイズ・連射音の区別(実測 0.70 / 0.00 / 0.00 / 0.00)
- BGM より 5 dB 小さい話し声を選び直せる

行けなかったこと(音声認識を入れないと解けない):

- **音楽のトレモロ(6 Hz)を発話と区別できない**(実測 0.86 で誤検出)。
  「音節の間隔のばらつき」で分ける案も実測したが、ノイズが最も人らしく
  なってしまい使えなかった
- BGM より 8.5 dB 以上小さい話し声は拾えない
- 当然ながら**字幕は作れない**(何を言ったかは分からない)

つまり近似で埋まるのはここまで。字幕とテロップ本文の自動化、そして
「大事なことを言っている場面」の判定は、D1 の決定が要る。
